# Expense Tracker

A simple console app in Python for tracking personal expenses.

## Features

- Add an expense (amount, category, description, date is set automatically)
- Show all expenses in a table
- Remove an expense by ID
- Show totals: overall and by category
- Data is saved to a JSON file, so it stays after closing the program

## How to run

1. Install Python 3.
2. Clone the repository:
   `git clone https://github.com/xaAqilbek/expense-tracker.git`
3. Run the program:
   `python main.py`

## Tech

- Python 3
- Standard library only: `json`, `os`, `datetime`
